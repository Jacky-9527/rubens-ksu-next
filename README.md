# rubens-ksu-next

Redmi K50 (rubens) KernelSU Next kernel builder via GitHub Actions.

## Usage

1. Push to `main` branch or manually trigger from Actions tab
2. Wait ~20-30 minutes for build
3. Download `rubens-ksu-next-kernel` artifact from Actions page
4. Use `Image` file to replace kernel in your stock boot.img

## How to flash

See [Actions](../../actions) for latest build artifact.
